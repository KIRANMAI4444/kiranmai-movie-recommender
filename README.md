# 🎬 Movie Recommendation System

A web-based movie recommendation system built with Flask that suggests Telugu movies based on genre. Users can search movies, add new ones, and get personalized recommendations.

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Flask](https://img.shields.io/badge/Flask-2.0+-green.svg)
![Status](https://img.shields.io/badge/Status-Active-brightgreen.svg)

---

## ✨ Features

- 🎯 **Get Recommendations** - Find movies by selecting any genre
- ➕ **Add Movies** - Expand the collection with new movies
- 🔍 **Search Movies** - Search across all genres instantly
- 📚 **View All** - Browse complete movie database
- 🎨 **Modern UI** - Beautiful dark theme with smooth animations
- 📱 **Responsive** - Works on desktop, tablet, and mobile

---

## 🛠️ Technologies Used

### Backend
- **Python 3.8+** - Core programming language
- **Flask 2.0+** - Web framework
- **Jinja2** - Template engine

### Frontend
- **HTML5** - Structure
- **CSS3** - Styling with animations
- **JavaScript** - Interactive elements
